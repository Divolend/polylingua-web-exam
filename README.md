# PolyLingua - Сайт языковой школы

Экзаменационный проект по дисциплине "Основы веб-технологий"

## Описание проекта

PolyLingua - это современный веб-сайт языковой школы, позволяющий студентам просматривать доступные курсы иностранных языков, выбирать репетиторов и оформлять заявки на обучение.

## Функциональность

### Главная страница
- Информация о языковой школе
- Преимущества изучения иностранных языков
- Список доступных языковых курсов с поиском и пагинацией
- Таблица репетиторов с фильтрацией по языку, уровню и опыту
- Форма оформления заявки на курс или занятия с репетитором

### Личный кабинет
- Просмотр всех заявок пользователя
- Подробная информация о каждой заявке
- Редактирование существующих заявок
- Удаление заявок
- Пагинация списка заявок

## Технологии

- **HTML5** - семантическая разметка
- **CSS3** - стилизация и адаптивный дизайн
- **Bootstrap 5.3** - UI-фреймворк
- **JavaScript (ES6+)** - клиентская логика
- **Fetch API** - взаимодействие с сервером
- **Git** - система контроля версий

### Endpoints
- `GET /courses` - получить список курсов
- `GET /tutors` - получить список репетиторов
- `GET /orders` - получить список заявок пользователя
- `POST /orders` - создать новую заявку
- `PUT /orders/{id}` - обновить заявку
- `DELETE /orders/{id}` - удалить заявку

## Особенности реализации

### Расчет стоимости курса
Стоимость курса рассчитывается по формуле:
```
Общая стоимость = ((courseFeePerHour × durationInHours × isWeekendOrHoliday) + 
                   morningSurcharge + eveningSurcharge) × studentsNumber
```

С учетом дополнительных опций:
- Скидка за раннюю регистрацию (≥30 дней): -10%
- Скидка за групповую запись (≥5 человек): -15%
- Интенсивный курс (≥5 часов/неделю): +20%
- Дополнительные материалы: +2000₽ на студента
- Индивидуальные занятия: +1500₽ за неделю
- Культурные экскурсии: +25%
- Оценка уровня: +300₽
- Интерактивная платформа: +50%

### Валидация
- Все формы проходят валидацию на стороне клиента
- Обязательные поля отмечены в формах
- Даты и время проходят проверку на корректность

### Адаптивность
Сайт полностью адаптирован для мобильных устройств с использованием Bootstrap Grid System.
